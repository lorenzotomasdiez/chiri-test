Launch Notes: Field Notebook v2

Field Notebook v2 represents our most significant update to the mobile writing experience. We've rebuilt the core syncing engine from the ground up to ensure that every keystroke is preserved across devices, even in low-connectivity environments. The goal was to eliminate the friction between thought and digital capture.

The new interface prioritizes vertical rhythm and clarity, allowing the user to focus entirely on the content withoutdistractions from unnecessary UI chrome.

This version of the application includes several brand new features that we think our users will really appreciate for their daily work. V2 introduces powerful new tools designed to accelerate your daily workflow.

auto_awesome Shortened for clarity
  • Zero-latency local-first storage
  • E2E encrypted collaborative editing
  • Customizable markdown themes

Advanced users can modify their local environment via the notebook.config.yaml as an inline code span. We've simplified the schema to support rapid experimentation with fonts and spacing.
